=============================================================
SOLUÇÃO PARA ERRO: Internal build system error
=============================================================

SOLUÇÃO SIMPLES (tente primeiro):
----------------------------------
1. Feche o Unity completamente
2. Reabra o Unity pelo Unity Hub
3. Aguarde reimportar os assets
4. Pronto!

SOLUÇÃO AVANÇADA (se o erro persistir):
---------------------------------------
1. Feche TODO o Unity (e Unity Hub também)
2. Execute o arquivo: fix-unity-build-error.bat
3. Aguarde a limpeza terminar
4. Reabra o Unity Hub
5. Abra o projeto

CAUSA DO ERRO:
--------------
O sistema de build do Unity (Bee) travou durante uma operação.
Isso geralmente acontece ao:
- Importar muitos arquivos de uma vez
- Trocar de plataforma de build
- Compilar scripts grandes

ARQUIVOS MUSICAIS:
-----------------
Os arquivos de música já foram copiados para:
Assets/Audio/Music/

Quando o Unity reabrir, ele vai importá-los automaticamente.
