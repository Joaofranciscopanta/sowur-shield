🌾 Sowur Shield - Demo

Build #1 - November 2025

📝 Release Notes

✨ Core Features

  • Advanced farming system with multi-stage crop growth
  • Soil state management (Till, Water, Plant, Harvest)
  • 36-slot inventory with drag & drop UI
  • Interactive dialogue system with branching conversations
  • NPC memory system - they remember your conversations!
  • Tool-based interaction (Hoe, Watering Can, Shovel)
  • Automatic selling system via SellBox
  • Day/night cycle with time management
  • Sleep system to advance time and trigger sales
  • Dual-grid tilemap rendering system

🆕 Recent Updates

  • Minimap System: 3-state minimap (Normal, Semi-transparent, Fullscreen)
  • Animal System: Chickens with AI behavior and interaction
  • Improved UI: Enhanced interaction prompts and visual feedback
  • Main Menu: Professional menu with settings and credits
  • Scene Transitions: Smooth loading screens with tips
  • Bug Fixes: Resolved NPC interaction and tool priority issues

🎯 Controls

  • WASD/Arrows: Move character
  • E: Interact with NPCs/objects
  • Left Click: Use equipped tool/interact
  • I: Open/close inventory
  • M: Toggle minimap modes
  • 1-9: Quick select inventory slots
  • ESC: Open game menu
  • Shift: Sprint

🎮 How to Play

  • Use the Hoe to till soil (converts ground to farmland)
  • Use Watering Can to water tilled soil
  • Plant seeds on watered soil
  • Wait for crops to grow over several days
  • Harvest mature crops with Left Click
  • Sell items by placing them in the SellBox
  • Sleep in bed to advance time and complete sales
  • Talk to NPCs with E key for branching dialogue

ℹ️ Demo Notes

  • Save/Load functionality disabled in demo build
  • Play session resets on page refresh
  • This is a showcase build - full version in development
  • Built with Unity 2022.3.46f1 LTS
