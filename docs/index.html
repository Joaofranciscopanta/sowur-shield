🌾 Sowur Shield - Demo

Build #1 - February 2026

📝 What's New

🐔 Animal Husbandry

  • Pet animals daily for happiness bonus & heart particles
  • Feed animals directly or stock the Feeding Trough
  • Happiness system (0–100) affects production output
  • Animal Roster UI — track all your farm animals at a glance

💾 Multiple Save Slots

  • 4 slots: AutoSave + Slot 1, 2, 3
  • Play time tracked and displayed per slot
  • Auto-save triggers every time you sleep
  • Delete individual slots from the Load screen

⚙️ Game Balance Tuning

  • Centralized GameBalance ScriptableObject
  • Sell multiplier, interaction ranges, happiness values — all in one place

✨ Core Features

  • Advanced farming (Till → Water → Plant → Harvest)
  • 36-slot inventory with drag & drop
  • Branching NPC dialogue with memory system
  • Tool-based interaction (Hoe, Watering Can, Shovel)
  • Automatic selling via SellBox on sleep
  • Day/night cycle & seasonal calendar
  • 3-state Minimap (Normal / Semi-transparent / Fullscreen)
  • Dual-grid tilemap rendering system

🎯 Controls

  • WASD / Arrows: Move
  • E: Interact with NPCs, objects, animals
  • Left Click: Use equipped tool
  • I: Open inventory
  • M: Toggle minimap
  • 1–9: Hotbar quick select
  • ESC: Game menu / Save & Load
  • Shift: Sprint

🎮 How to Play

  • Use the Hoe to till soil
  • Use the Watering Can on tilled soil
  • Plant seeds on watered soil and wait for growth
  • Harvest with Left Click when crops are ready
  • Drag items into the SellBox — earnings collected on sleep
  • Talk to NPCs with E for branching dialogue
  • Pet & feed your animals every day to maximize production
  • Sleep in bed to advance the day, auto-save, and collect earnings

ℹ️ Demo Notes

  • This is a showcase build — full game in active development
  • Session resets on page refresh
  • Built with Unity 2022.3.46f1 LTS
