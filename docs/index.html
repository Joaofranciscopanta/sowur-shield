🌾 Sowur Shield

Build #2 — February 2026

What's New

🐔 Animal Husbandry

  • Pet animals daily for happiness & heart particles
  • Feed via inventory or Feeding Trough
  • Happiness (0–100) affects production output
  • Animal Roster UI to track all your animals

💾 Multiple Save Slots

  • 4 slots: AutoSave + Slot 1, 2, 3
  • Play time displayed per slot
  • Auto-save on every sleep
  • Delete slots from the Load screen

✨ Core Features

  • Farming: Till → Water → Plant → Harvest
  • 36-slot inventory with drag & drop
  • Branching NPC dialogue with memory
  • Automatic selling via SellBox on sleep
  • Day/night cycle & seasonal calendar
  • 3-state Minimap (Normal / Semi / Fullscreen)

🎯 Controls

  • WASD: Move
  • E: Interact
  • Left Click: Use tool
  • I: Inventory
  • M: Minimap
  • 1–9: Hotbar
  • ESC: Menu / Save
  • Shift: Sprint

🎮 How to Play

  • Hoe → till soil
  • Watering Can → water it
  • Seeds → plant & wait
  • Left Click → harvest
  • SellBox → drag items, earn on sleep
  • Pet & feed animals every day
