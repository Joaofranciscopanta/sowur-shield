🎮 Sowur Shield - Demo

Version 1.0 - October 2025

📝 Release Notes

✨ Features

  • Advanced farming system with multi-stage crop growth
  • 36-slot inventory with drag & drop
  • Interactive dialogue system with branching conversations
  • Tool-based interaction (Hoe, Watering Can, Shovel)
  • Automatic selling system via SellBox
  • Day/night cycle with time management
  • Dual-grid tilemap system

🎯 Controls

  • WASD/Arrows: Move
  • E: Interact
  • Left Click: Use tool/interact
  • 1-9: Select inventory slot
  • ESC: Open menu

ℹ️ Demo Notes

  • Save/Load disabled in demo build
  • Play session resets on page refresh
  • Full version available on request
