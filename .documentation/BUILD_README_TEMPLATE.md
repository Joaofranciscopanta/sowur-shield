# Sowur Shield - Demo Build

## 🎮 About This Demo

This is a demo build of **Sowur Shield**, a 2D farming simulation game built in Unity. This demo showcases the core gameplay mechanics and recent improvements to the game.

## ⚠️ Demo Limitations

**This is a DEMO BUILD with the following limitations:**

- ❌ **No Save/Load Functionality** - Progress is not saved between sessions
- ❌ **Single Session Only** - Game resets when closed
- ✅ **Full Gameplay** - All core features are functional within a session

This demo is designed to showcase the game's features and recent updates. For the full experience with save functionality, please check out the full release.

## 🎮 How to Play

### Windows:

2. Run `Sowur Shield Demo.exe`
3. Play!

1. Open `index.html` in a modern web browser (Chrome, Firefox, Edge recommended)

## 🕹️ Controls

### Movement:
- **WASD** or **Arrow Keys** - Move player
- **Shift** - Sprint (if implemented)

### Interactions:
- **E Key** - Interact with objects, NPCs, and buildings
- **Left Mouse Button** - Use tools, interact with UI
- **Right Mouse Button** - Use items, split stacks (with Shift)

### Inventory:
- **I Key** or **Tab** - Open/Close inventory
- **1-9 Number Keys** - Select hotbar slots
- **Drag & Drop** - Move items between slots

### UI:
- **ESC** - Open/Close game menu
- **Mouse** - Navigate menus and UI

---

## 🌾 Gameplay Tips

1. **Start Farming**: Use the hoe to till soil, plant seeds, and water crops
2. **Harvest & Sell**: Collect grown crops and place them in the SellBox
3. **Sleep to Sell**: Go to bed to end the day and receive money for sold items
4. **Explore**: Talk to NPCs, discover new areas
5. **Manage Inventory**: Use number keys for quick access to tools and items
